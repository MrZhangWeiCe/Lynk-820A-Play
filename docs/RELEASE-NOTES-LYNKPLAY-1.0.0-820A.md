# LynkPlay 1.0.0-820A

发布日期：2026-10-07。基于 DiPlay 0.2.13，versionCode 33。

## 适配范围

领克 01 全球版，820A 车机，Android 9（API 28），`dcy11_a1 / PQ3B.190801.002` 固件识别范围。不是领克全车型通用适配。

## 修改

- 应用与 CarPlay 接收端名称为 LynkPlay；CarPlay 内 OEM 返回按钮为 Lynk，使用领克图标。
- 恢复返回车机桌面；补充 Android 9 媒体按键兼容与方控指令诊断。
- 播放器遵循音频焦点设置，820A 新偏好默认开启；辅助媒体按键会话不重复申请焦点。
- 无线交接完成后，尝试定向隔离当前 iPhone 的原生蓝牙音乐/电话通道。保留总蓝牙、配对及其他设备，不修改永久连接策略；仅会话内限制重试。
- 增强导出的音频、媒体控制、蓝牙状态与断开结果诊断。

## 验证与限制

已实车确认能够连接；关闭手机蓝牙并播放一次车机原生音乐后，CarPlay 音乐正常。原生蓝牙重新连接与暂停相关。最新音源激活、蓝牙定向隔离仍需实车复测，方控全项、通话和 Siri 尚未完整验收。

release 构建与定向自动化测试通过，不等于稳定性或全部实车功能验收通过。隐藏蓝牙接口可能被车机固件拒绝。隔离会尝试断开原生蓝牙电话通道；请停车测试。

## 签名与安装

按用户选择沿用此前测试包的 Android debug 签名，非新正式签名。release 构建、非 debuggable。相同签名且相同应用 ID `com.shihab.diplay` 可覆盖安装；它替换 DiPlay，不能与同 ID DiPlay 共存。

覆盖安装后开启“音频焦点”，重新连接。保持手机蓝牙开启，不先启动车机原生音乐，播放一分钟检查能否直接出声和是否暂停；导出新日志反馈。
